# dsh-themes

Five comfortable dark themes for DeepSeek Harness, implemented through DSH's native semantic theme registry:

- Catppuccin Mocha
- Gruvbox Dark
- Nord
- Tokyo Night
- Dracula

After installation and a DSH restart, open **Settings → Themes**. The selected theme is stored locally in `~/.dsh/community-theme.json`; no browser data or credentials leave the machine.

Install from this repository with:

```sh
./scripts/install.sh themes
```

The color palettes are community conventions associated with their respective open-source projects. This plugin's integration code is MIT licensed and is not affiliated with those projects or DeepSeek.
